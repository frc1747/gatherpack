## 🧪 Try this build

Run it in Docker with the Northwind sample data loaded. You need Git, Docker with Compose v2, and `openssl`; it runs as its own stack, named `hbr-demo`.

> [!NOTE]
> This build isn't a release yet, so these steps run the latest release, `v0.0.0-hbr.31`.

```bash
git clone https://github.com/frc1747/gatherpack.git hbr-gatherpack-demo
cd hbr-gatherpack-demo
git checkout v0.0.0-hbr.31
cat > .env <<SETTINGS
COMPOSE_PROJECT_NAME=hbr-demo
GATHERPACK_IMAGE=ghcr.io/frc1747/gatherpack
GATHERPACK_TAG=0.0.0-hbr.31
ROOT_URL=http://localhost:3000
SECRET_KEY_BASE=$(openssl rand -hex 64)
DATABASE_PASSWORD=$(openssl rand -hex 16)
JOBS_DASHBOARD_PASSWORD=$(openssl rand -hex 16)
SETTINGS
docker compose -f docker-compose.production.yml up -d db
docker compose -f docker-compose.production.yml run --rm web ./bin/rails db:create db:schema:load
docker compose -f docker-compose.production.yml run --rm web ./bin/rails hbr:sample_data
docker compose -f docker-compose.production.yml up -d
```

Then open `http://localhost:3000` and sign in as `admin@example.com` with the password `password123`. To remove it and all of its data: `docker compose -f docker-compose.production.yml down -v`.

[`fork/sample_data/README.md`](fork/sample_data/README.md) has every step explained, the other logins, what to try in each feature, and how to load the data into a copy you already run.

<a id="feature-signups"></a>

### 📋 Sign-up sheets

Sheets where people sign up to work or bring things at events, such as greeters, a first aid table, or the pizza for a lunch. A position asks for people (a number of places) or items (a quantity, like 6 pizzas), and can ask one question. Rules say who may take it: a badge, an age range, or being on any of a list of teams. Organizers hold a badge you choose, run their own sheets without managing a team, and mark who showed up or brought their items. An admin turns it on in Settings.

- 👥 **Who uses it:** Everyone signs up; organizers run the sheets; admins choose the organizer badge
- ⚙️ **Settings:**

<a id="feature-signup-credit"></a>

### 🤝 Sign-ups count toward commitments

A sign-up sheet, or one position on it, can count toward a commitment: signing up shows as planned, and showing up or bringing the items counts it. A sign-up made on behalf of someone credits that person, so a parent working a place for their child credits the family. The sign up dialog shows how much each person still owes. It has no setting of its own and works while Sign-up Sheets and Commitments are both on.
